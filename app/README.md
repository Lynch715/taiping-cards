# 太平天国 · 军报 v0.6.0

按 `docs/06-技术方案.md` v0.2，只做网页版：React 18、TypeScript strict、Vite 6、PixiJS 8、PWA。

```sh
cd app
npm ci
npm run data
npm run dev
```

开发网址 http://127.0.0.1:5191 。生产预览与 PWA 验收：

```sh
npm test
npm run build
npm run preview
```

预览网址 http://127.0.0.1:5192 。PWA 只在生产构建启用。完整部署流程见 [DEPLOY.md](DEPLOY.md)；`npm run package:static` 产出 `release/taiping-web/`。

- CSV 是唯一数值源；构建校验生成数据新鲜度。两条战役线各八章、每章六关；逐章开放。武将独立升级 / 升星，军需放置上限十二小时，每关每日三次扫荡、两阵营合计每日30次上限；装备掉落、强化、分解和转移，单抽与十连保底均使用纯函数规则。
- `runBattle` 是无 DOM、无时钟、无存储的纯函数；两端 mulberry32，100 组金标准逐行对照。Pixi 只播放日志。
- IndexedDB 沿用原 M1 库与键名；成长数据以 growth.schema=1 扩展，旧军册首次迁移保留进度与编队，并补入对应首通军需，不追溯放置时间。页面上方“军册备份”提供 JSON 导出/导入，导入校验后展示摘要，确认替换才写入。更新与离线缓存不清军册。
- 清单含 192/512 图标、竖屏与宣纸色；SW 分程序与内容两层缓存；初装仅下载程序和首章缩图，详情 full.webp 按需缓存。新版本下载完成后提示“有新版本，点击刷新”，战斗中不会自动刷新。
- `?qa=英文标签` 使用独立测试军册。实际界面验收优先用 Codex In-app Browser；浏览器与真机安装结果分开记录，真机按随包清单核验。
- 字体为本地 Noto Serif SC 子集，OFL 授权在 public/fonts/OFL.txt。美术文件保持原图，新增图标沿用朱砂“军”印。

养成、经济模型、逐关校准、混合装备金标准见 `assets/reports/progression/`。此前缓存、两章难度与金标准证据见 `assets/reports/web_chapter2/`。M1.1 安装和离线截图保留在 `assets/reports/m1_1/`（相对项目根目录）。旧 M1 原生验收报告保留为历史记录，不代表当前交付目标。
