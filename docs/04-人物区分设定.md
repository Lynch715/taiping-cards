# 04 人物区分设定

> 状态：v0.1，首批 13 位 SSR。出图时本文件优先于 `01-美术规范.md` 的通用人物描述。
> 起因：首批 SSR 中太平天国诸王全部以已定稿的石达开为参考图生成，导致脸、服装、姿势完全一致；清朝一排服装与姿势也近乎相同。

## 1. 核心原则：每张卡画的是"这个人的代表性时刻"

不画"某阵营的标准形象"，而画**这个人物最有代表性的历史时刻**。时刻决定服装、道具、姿态、背景。同一阵营的人可以同穿官服，但不能同时出现在同一类场合。

## 2. 生成规则（硬性）

1. **禁止把其他人物的成稿当参考图。** 任何 `assets/raw/characters/*.png` 都不能出现在别人的 references 里。
2. **风格参考不带人脸。** 不再提交罗大纲全图；改为提交 `docs/reference/style_swatch_*.png`（从母图裁出的衣服、背景局部，无人脸）+ 本人物的背景板。
3. **先定脸，再画全身。** 每人先出头像设定图（只附本人画像/照片，不附风格参考），确认后再以"头像 + 无脸风格参考"出全身。
4. **提示词顺序：人物块放最前面。** 外貌、时刻、服装、姿态写在前，风格块、构图块放在后。
5. **剪影测试。** 全部人物涂黑，按阵营分成太平天国／清朝两行排列（双阵营按本次清军时期形象归入清朝行，不重复计数），必须能凭剪影分出谁是谁。验收时 Codex 同时提交 `assets/reports/silhouette_sheet.png`。
