# 05 战斗与数值

> 状态：v0.1 草案。所有数值是**初始设计值**，须经 Codex 按第 10 节的平衡模拟调整后才算定稿。
> 数据表：`data/heroes.csv`、`data/skills.csv`、`data/bonds.csv`、`data/equipment.csv`、`data/equipment_sets.csv`、`data/exclusive_equipment.csv`。

## 1. 战斗形式

- 放置自动战斗，双方各 **5 名上阵武将 + 1 个君主位**。
- 站位：**前排 2 人、后排 3 人**。
- 回合制：每回合所有存活武将按**速度从高到低**依次行动；速度相同时，玩家方优先，再按站位编号。
- 上限 **20 回合**；到时未分胜负，进攻方判负。
- 行动：怒气满 100 时释放**主动技**（并清空怒气），否则普攻。

### 1.1 君主位

不上场、不会被攻击。提供一条**政令**（全程被动光环），并在指定回合自动发动一次**诏令**。
可放入君主位的卡：洪秀全、洪天贵福、咸丰、慈禧、恭亲王、肃顺（`heroes.csv` 中 `position=君主`）。君主卡不能上阵。

## 2. 属性

| 属性 | 含义 | 影响 |
|---|---|---|
| 统（统率） | 带兵、防守 | 生命、物防 |
| 武（武力） | 单兵战斗 | 物攻；少量生命 |
| 智（智谋） | 谋略 | 谋攻、谋防 |
| 速（速度） | 机动 | 出手顺序、怒气获取 |

**主攻属性**：步、骑、水、火 用 **武**；谋 用 **智**（谋士的普攻是计策，按谋攻打谋防）。

### 2.1 战斗属性换算

```
成长 G = (1 + 0.06 × (等级 − 1)) × (1 + 0.15 × (星级 − 1))
生命 HP  = (统 × 24 + 武 × 6) × G
物攻 ATK = 武 × 3 × G
谋攻 INT = 智 × 3 × G
物防 DEF = 统 × 1.2 × G
谋防 RES = 智 × 1.0 × G
速度 SPD = 速 + 装备速度（不随等级成长）
```

- 等级 1–100；星级 1–6。初始星级：普通 1★、稀有 2★、传说 3★。升星消耗本卡碎片。
- 暴击率基础 5%，暴击伤害 150%。

### 2.2 属性预算（设计约束）

以 **有效值 E = 统 + 主攻属性 + 速** 衡量强度（另一项进攻属性只影响少量生命或技能附带效果）：

| 稀有度 | E 目标 | 允许范围 |
|---|---|---|
| 传说 SSR | 270 | 265–275 |
| 稀有 SR | 250 | 246–254 |
| 普通 R | 230 | 226–234 |

君主卡不计 E，其智（洪秀全、慈禧等）或统决定政令强度。

## 3. 伤害公式

```
普攻伤害 = 攻 × 攻 / (攻 + 防)            攻=ATK 或 INT，防=DEF 或 RES（同类相对）
技能伤害 = 系数 × 攻 × 攻 / (攻 + 防)
最终伤害 = 上式 × 兵种克制 × 地形 × (1 + 增伤 − 减伤) × 暴击
治疗 / 护盾 = 按目标最大生命的百分比
```

- 增伤、减伤同类相加，最终减伤下限为 −60%（即最多减免 60%）。
- 伤害取整，最低 1。

## 4. 怒气

- 上限 100。普攻后 **+25**，每次受到伤害 **+10**，速度每高于 80 一点，普攻后额外 +0.5。
- 主动技释放后清零。眩晕、沉默期间仍会累积怒气，但沉默时不能释放主动技。

## 5. 兵种

| 兵种 | 普攻目标 | 特性 |
|---|---|---|
| 步 | 敌方前排（前排全灭后打后排） | 位于前排时受到伤害 −10% |
| 骑 | 敌方前排；30% 概率改打后排 | 第 1 回合速度 +20 |
| 水 | 敌方前排 | 水战地形全属性 +20%；非水战地形攻击 −10% |
| 火 | 任意一名敌人（优先生命最低者） | 普攻射程无限；位于后排时受到伤害 −10% |
| 谋 | 敌方前排 | 开场怒气 +30；主动技伤害 +15% |

**克制**（攻方对守方伤害 ×1.2）：骑 → 步，步 → 火，火 → 骑。水、谋不参与克制。

## 6. 地形（关卡属性）

| 地形 | 效果 |
|---|---|
| 陆战 | 无 |
| 水战 | 水师特性生效 |
| 攻城 | 防守方全体防御 +20% |
| 守城 | 玩家为防守方，玩家方全体防御 +20% |

## 7. 阵营机制

上阵 5 人中**同一阵营 ≥ 3 人**时，该阵营机制生效；一周目只能单阵营编队，所以必然生效。二周目混编时，可能两边都不生效。双阵营卡（程学启、张国梁、白齐文）按编入的阵营计数。

### 7.1 太平天国：信仰 与 猜忌

- **信仰**：开场 50，上限 100。我方击杀 +10，我方释放主动技 +5。
  满 100 时进入「天国」状态：太平天国武将攻击 +20%，持续 2 回合，结束后信仰回到 50。
- **猜忌**：开场 0，上限 100。只由特定人物与羁绊增加（见 `bonds.csv` 的「天京事变」）。
  满 100 时触发「天京事变」：杨秀清、韦昌辉各损失 50% 当前生命；石达开若在场，立即离开战场（不算阵亡）；猜忌清零，本场不再增加。

### 7.2 清朝：粮饷

- 开场 0，每回合开始时 +10，无上限。
- 每累计满 30，清朝武将防御 +5%，最多 5 层（+25%）。
- 设计意图：太平军开局爆发，清军越拖越强。

## 8. 技能关键词（`skills.csv` 的效果文本只使用这些词）

| 关键词 | 规则 |
|---|---|
| 伤害 N% | 技能伤害公式中的系数 |
| 单体 / 前排 / 后排 / 全体 / 随机 N 名 | 目标范围 |
| 回复 N% | 按目标最大生命 |
| 护盾 N% | 按目标最大生命，持续标注的回合数 |
| 攻击 / 防御 / 速度 ±N%（或 ±N 点） | 增益、减益，同名不叠加取最高，不同来源可以叠加 |
| 眩晕 | 跳过行动 |
| 沉默 | 不能释放主动技 |
| 嘲讽 | 敌方普攻和单体技能必须以其为目标 |
| 灼烧 | 每回合结束受到 施加者 ATK × N% 的伤害 |
| 驱散 | 移除减益 |
| 免死 | 受到致命伤害时保留 1 点生命 |
| 连击 | 立刻再进行一次普攻 |

技能里的"湘军武将""淮军武将""洋枪队武将""外籍武将"按 `heroes.csv` 的 `tags` 列判断；"骑兵""火器武将""水师武将"按 `troop` 列判断。

## 8.1 装备

- 普通装备 4 个部位：兵刃（攻击）、甲胄（生命）、坐骑（速度）、兵书（谋防、开场怒气）。品质 粗 / 制 / 精 / 珍 / 绝，强化每级 +10% 基础值，上限见 `equipment.csv`。
- 5 个套装（圣兵、勇营、洋械、铁骑、江防），2 件、4 件生效；任何武将都能穿，但主题对应各自阵营或兵种。**套装效果不得引用阵营资源（信仰、猜忌、粮饷）**，否则对另一阵营无效，会造成不对称（v0.2 平衡模拟发现）。
- 专属装备：SSR、SR 每人一件，4★ 解锁，提供属性加成并强化本人一个技能（`exclusive_equipment.csv`）。`basis_flag`：史=有实物或史料依据，设=美术设定，传=传说。

## 9. 羁绊与宿敌

- **正面羁绊**：同队成员达到人数即生效；君主位上的卡也算在队中。
- **负面羁绊**：同队即生效，效果写在 `bonds.csv`。
- **宿敌**：双方分属敌我两边时生效，只对写明的一方有效。

## 10. 平衡模拟（Codex 施工）

写 `tools/battle_sim.py`，按本文件实现战斗，用 `data/*.csv` 作输入，跑大量随机对局，输出 `assets/reports/balance_report.md`。

平衡目标：

| 指标 | 目标 |
|---|---|
| 同等级、同星级，SSR 对 SR 单挑胜率 | 65–75% |
| 5 名 SSR 对 5 名 SR（同等级） | 胜率 ≥ 80% |
| 战斗平均回合数 | 8–12 |
| 太平对清，同稀有度随机阵容胜率 | 45–55%（短局太平占优、长局清占优是允许的，但总胜率要平） |
| 任意单卡在胜率前 10% 阵容中的出场率 | ≤ 60% |
| 天京事变：杨秀清 + 洪秀全君主，无韦昌辉 | 12 回合内触发率 < 50% |
| 天京事变：再加上韦昌辉 | 12 回合内触发率 > 90% |

调整优先级：先改技能系数，再改属性；属性改动后仍须满足第 2.2 节预算。每次调整写进报告。

调参约束（v0.3 补充）：

1. **招牌机制不能削成零头。** 每人技能里体现其史实特点的那一项（如石达开"孤军远征"、洪秀全"天王诏旨"、曾国藩"屡败屡战"），百分比加成不低于 10%。嫌强时改触发条件或加代价，不要削数值。
2. **普通卡单项效果上限 25%**（加成、减益、护盾、回复均适用）。
3. **君主卡单独统计。** 出场率改为"在本阵营可选君主中被选中的比例"，不和战斗卡放在一起比；目标是同阵营每个君主都有 ≥ 20% 的选用率。
4. **专属装备逐件诊断。** 4★ 专属测试要列出每件专属对本人胜率的提升，提升最大的几件优先调整。
