# 01 美术规范

> 状态：v0.2，补充首批验收确认的角帽材质与靴型。所有人物卡、背景、剧情插图都按本文件出图；改动需同步更新版本号。

## 1. 总体风格

**人物卡：历史油画厚涂。**
风格母图：`docs/reference/style_master_luo_dagang.png`（罗大纲测试图）。**v0.2 起不再把母图整张作为参考提交**（会把罗大纲的脸带给所有人），改用从母图裁出的无脸局部；人物区分规则见 `04-人物区分设定.md`。

| 维度 | 要求 |
|---|---|
| 笔触 | 可见的油画厚涂笔触，边缘略松，不要 CG 式光滑塑料感 |
| 比例 | 写实比例，约 7.5 头身；不要动漫大眼、不要韩式美颜脸 |
| 面孔 | 中国南方/华中人相貌，按史实年龄绘制（见 `data/characters.csv` 的 `appearance_age`）；有沧桑感，可以有皱纹、疤痕、胡茬 |
| 光线 | 自然戏剧光，左上主光 + 背后轮廓光（统一方向，方便和背景合成） |
| 色彩 | 整体低饱和、偏土色；只有阵营色（赤/黄或石青/金）允许高饱和 |
| 气质 | 庄重、粗粝、有历史重量；不要仙侠、不要奇幻盔甲 |

**剧情插图：晚清石印线描。**
参考《点石斋画报》：黑色线描为主，可加淡彩（赭石、花青、淡朱），横构图 16:9，人物众多、叙事性强。屠城、天京事变等黑暗剧情用这种风格表现，不画写实血腥特写。

## 3. 史实服饰硬性规则（出图必查）

| 项目 | 太平天国 | 清朝 |
|---|---|---|
| 发式 | **蓄发、不剃额、无辫子**，长发用红/黄头巾包裹或束起 | **剃前额、留辫子** |
| 首领 | 本项目诸王采用**刺绣织物软角帽**，保留顶部双卷角、两侧流苏、双龙与海水江崖纹，用金线刺绣表现；**不是金属皇冠、牛角或维京角盔**。黄/红袍绣龙；出图前须提供博物馆文物或原始史料图版参考 | 官员戴顶戴花翎，穿石青补服，挂朝珠；补子图案按品级（文官禽、武官兽）；亲王、帝后按各自服制与画像处理 |
| 士兵 | 号衣，胸背圆形字补 | 湘军、淮军穿勇营号衣，胸前"勇"字；八旗按旗色 |
| 鞋 | 布鞋、草鞋、传统靴；诸王站姿采用高筒、厚底布靴，**不用黄色麂皮矮帮沙漠靴形** | 男性黑色高筒朝靴、布靴，白色层叠厚布底；帝后女性另按旗鞋服制与画像核对；**禁止任何现代鞋形** |
| 武器 | 刀、矛、旗；后期可有洋枪 | 刀、矛、抬枪；后期洋枪洋炮 |

禁止项：日式、韩式甲胄；奇幻盔甲；现代鞋、拉链、纽扣式西装（外籍人物除外）；画面里的文字和乱码。

有真实照片或画像的人物（曾国藩、李鸿章、左宗棠、僧格林沁、戈登、华尔），出图时必须附参考图，面部要像本人。

参考记录须说明来源、能证明的内容与限度。角帽原始图版不能证明某个人的精确私服；晚年画像不能直接证明其年轻时面貌。未取得可靠同龄参考的重建、原始馆藏链不完整的图像，须在本批报告中注明。首批已通过的罗大纲和曾国藩原图作为基准保存，后续人物逐张附母图，避免笔触逐渐变光滑。

## 4. 资产规格（核心：只缩放，不裁切）

每个人物只有**一张主立绘**。游戏里所有尺寸都是把主立绘**整张等比缩小**，任何界面都不裁切。

### 4.1 主立绘（合成后）

- 画布 **1024 × 1536**（2:3），PNG
- 由两层合成：**人物层**（透明底）+ **背景层**（场景板），合成由脚本完成，见 `03-资产管线.md`
- 人物一律**全身站姿**，正面或 3/4 侧面

人物在画布中的位置（脚本强制执行，单位 px）：

```
y=0     ┌────────────────────┐
        │  顶部带 0–92        │ ← 只放背景；UI 可叠加稀有度印、兵种徽
y=92    │        ○  头顶线    │
        │       /|\           │
        │        |   人物高 1300px（约 85%）
        │       / \           │
y=1392  │  ───── 脚底基线 ─── │
        │  底部带 1392–1536   │ ← 只放地面；UI 可叠加星级
y=1536  └────────────────────┘
        左右安全边距各 64px：人物（含武器、披风、旗帜）宽度 ≤ 896px
```

- **身高系数**（v0.2）：人物表 `height_scale` 列，取值 0.90–1.00，默认 0.96。人物目标高度 = 1300 × height_scale（四舍五入），脚底基线仍为 1392，因此头顶会低于 92 线，人物之间出现真实的高矮差。取值依据见 `04-人物区分设定.md` 第 6 节
- 人物水平居中（以人物外框中心对齐 x=512，可在 csv 里用 `x_offset` 微调）
- 人物过宽时，按宽度 896 缩小，脚底基线仍对齐 1392（此时人物会比 1300 矮，属正常）

### 4.2 派生尺寸（全部由主立绘整张缩小）

| 名称 | 尺寸 | 用途 |
|---|---|---|
| `full` | 1024×1536 | 卡牌详情、图鉴、招募展示 |
| `card` | 400×600 | 卡牌列表、编队选择 |
| `mini` | 160×240 | 战斗场景、队伍栏 |
| `thumb` | 96×144 | 图鉴网格、奖励弹窗 |

说明：因为不裁切，`mini` 和 `thumb` 尺寸下脸会很小，靠卡框颜色、阵营徽、兵种徽来辨认，这是有意的取舍。

### 4.4 稀有度表现（构图统一，靠以下要素区分）

| 稀有度 | 背景 | 特效层 | 卡框 |
|---|---|---|---|

## 5. 提示词模板

出图时按 `[风格块] + [人物块] + [构图块] + [禁止块]` 拼接。人物块中文、英文都可以，其余块用英文。

**风格块（固定）**
```
Historical oil painting, thick impasto brushstrokes, painterly loose edges, realistic proportions, earthy desaturated palette with strong faction accent colors, natural dramatic lighting from upper left with rim light from behind. Same art style as the reference image.
```

**人物块（每人不同，从 csv 生成）**
```
{英文身份描述}, {appearance_age} years old, {appearance_notes}, {faction costume rules}.
```

**构图块（固定）**
```
Full body standing pose, entire figure visible from head to feet, centered, figure occupies about 85% of image height, weapons, banners and clothing fully inside the frame, transparent background, no ground, no scenery, no text, no border, vertical 2:3.
```

**禁止块（固定）**
```
Not anime, not fantasy armor, not Japanese, not Korean, no modern shoes, no text, no watermark.
```
清朝人物另加：`shaved forehead with a long queue.`
太平人物另加：`long uncut hair, NO queue, NO shaved forehead.`

**背景板模板**
```
Historical oil painting background, thick impasto brushstrokes, {场景描述}, 1850s-1860s China, empty foreground ground area at the bottom for a standing figure, horizon around 88% of image height, light from upper left, no main characters, no text, vertical 2:3.
```

**剧情插图模板**
```
Late Qing lithograph illustration in the style of Dianshizhai Pictorial (1880s), black ink line drawing with light washes of ochre, indigo and pale vermilion, crowded narrative composition, {剧情场景描述}, horizontal 16:9, no modern elements, no readable text.
```

## 6. 出图验收清单（我检查时逐条看）

1. 发式、服饰、鞋符合第 3 节
2. 有照片的人物面部像本人
3. 人物是全身、完整，没有被画布边缘切掉
4. 画风与母图一致（笔触、饱和度、光向）
5. 年龄与 csv 的 `appearance_age` 相符
6. 图中无文字、无乱码、无水印
7. 管线报告中无放大倍数 > 1.25 的警告（说明原图人物太小、清晰度会不足）
