## 已定的设计决策

- 两个阵营都能玩；二周目可以混编
- 放置卡牌，自动战斗
- 剧情严格按史实；黑暗史实写进剧情（用石印风格插图表现）
- 人物卡画风：历史油画厚涂；母图为罗大纲测试图
- 立绘：统一全身像，1024×1536；所有界面**整张缩放、不裁切**
- 界面风格：宣纸 · 朱印 · 木版
- 竖屏 1080×1920；上阵 5 人（前 2 后 3）+ 君主位
- 数值 v1.0：第二轮平衡通过（`assets/reports/balance_report_v2.md`）
- 只做网页版，手机浏览器优先（竖屏），电脑居中显示：TypeScript + React + PixiJS + PWA
