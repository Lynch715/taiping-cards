# 02 界面规范

> 状态：v0.1。视觉效果见 `docs/界面样稿.html`（浏览器直接打开）。

## 1. 设计概念：宣纸 · 朱印 · 木版

界面像一份晚清的**军报、告示和公文**：宣纸做底，墨色写字，朱砂印章标重点，木刻线框做边。人物卡是油画，界面就要克制，不和立绘抢视线。

- 底：米黄宣纸纹理，不用纯白
- 字：墨色宋体，标题用粗宋
- 强调：朱砂红印章、圈点
- 边框：双线木刻框（外粗内细）
- 阵营界面换色：玩太平天国时强调色是赤与黄（像天朝诏书的黄绫），玩清朝时是石青与金（像奏折、补服）
- 战斗场景用深墨底，让油画立绘和特效更醒目

## 2. 色彩 Token

```css
:root {
  /* 基础 */
  --paper:        #EDE3CC;  /* 宣纸主底 */
  --paper-2:      #E2D5B8;  /* 次级底、卡片内底 */
  --paper-line:   #C9B994;  /* 宣纸上的分隔线 */
  --ink:          #1E1915;  /* 正文墨色 */
  --ink-2:        #4A4038;  /* 次要文字 */
  --ink-3:        #7A6E60;  /* 弱提示 */
  --cinnabar:     #A8261B;  /* 朱砂：印章、主按钮、警示 */
  --night:        #15110E;  /* 战斗场景底 */

  /* 阵营 */
  --tp-red:       #B0281C;
  --tp-yellow:    #D9A21B;
  --qing-blue:    #1E3550;
  --qing-gold:    #B8893B;
  --west-green:   #2F4A3A;

  /* 稀有度 */
  --r-bronze:     #8C5A32;
  --sr-silver:    #A9A9A3;
  --ssr-gold:     #C9A044;

  /* 战斗条 */
  --hp-ally:      #5E7F45;  /* 我方血条：石绿 */
  --hp-enemy:     #A8261B;  /* 敌方血条：朱砂 */

```

阵营主题通过根节点切换：`data-faction="taiping"` 时 `--accent: var(--tp-red); --accent-2: var(--tp-yellow)`；`data-faction="qing"` 时 `--accent: var(--qing-blue); --accent-2: var(--qing-gold)`。

## 3. 字体

| 用途 | 字体 | 字重 |
|---|---|---|
| 标题、人物名、按钮 | 思源宋体 Noto Serif SC | Black / Bold |
| 正文、技能描述 | 思源宋体 Noto Serif SC | Regular / Medium |
| 数字（属性、伤害） | 思源宋体，开启等宽数字 `font-variant-numeric: tabular-nums` | Bold |

两款字体都是 OFL 授权，可免费商用。人物名在卡牌详情页**竖排**（`writing-mode: vertical-rl`）。

字号（以 1080 宽设计稿为准）：标题 56 / 人物名 48 / 正文 30 / 小字 24 / 最小 20。

## 4. 画面基准

- 竖屏，设计稿 **1080 × 1920**；按宽度缩放适配
- 顶部安全区 120px，底部安全区 100px（刘海屏、手势条）
- 圆角：几乎不用圆角（最多 4px），保持木版、公文的方正感

## 5. 核心组件

### 5.1 人物卡（卡牌列表、编队）

```
┌───────────────────┐  ← 外框：双线木刻框，颜色=稀有度（铜/银/金）
│[阵营徽]      [印]  │  ← 叠在立绘顶部带（0–6%）：左阵营徽，右稀有度印
│                   │
│   主立绘整张缩放    │  ← 2:3，不裁切
│                   │
│ [兵种]     ★★★☆☆ │  ← 叠在立绘底部带（91–100%）
├───────────────────┤
│   石达开   Lv.40   │  ← 名牌：宣纸底，粗宋人物名
└───────────────────┘
```

- 卡牌整体比例约 2:3.35（立绘 2:3 + 名牌）
- 稀有度印：方形朱印，印文 凡 / 精 / 绝，印色按稀有度（铜、银、金框内底朱砂字）
- 阵营徽：太平"太平"圆印（赤底黄字）；清"清"方印（石青底金字）
- 兵种徽：步、骑、水、火、谋，单字圆徽

### 5.2 战斗小卡（`mini` 160×240）

- 立绘整张缩放 + 细框（阵营色）
- 下方：血条（我方石绿 / 敌方朱砂）+ 怒气条（明黄），怒气满时卡框发光
- 阵亡：立绘去色变灰，盖一个"殁"字朱印

### 5.3 按钮

- 主按钮：朱砂底、宣纸色字，像盖章；按下时轻微下沉
- 次按钮：宣纸底、墨色双线框
- 禁用：降低到 40% 不透明度

### 5.4 弹窗

- 宣纸底 + 木刻双线框，标题居中带两侧装饰短线
- 关闭按钮在右上，用"×"墨字，不用图标圆钮

## 6. 页面清单

| 页面 | 要点 |
|---|---|
| 阵营选择 | 一周目开始时选择太平天国或清朝；左右分屏，赤黄与石青金对比 |
| 主城 | 太平天国是"天京"，清朝是"大营"；下方 5 个导航：征战 / 编队 / 将领 / 招募 / 史册 |
| 征战（章节地图） | 一张古地图（长江流域），关卡点是朱印圆点，按史实章节连线推进；已通关的盖"捷"字印 |
| 关卡详情 | 关卡名、史实简介（2–3 行）、敌方阵容、推荐战力、奖励 |
| 编队 | 上阵 5 人（前排 2、后排 3），下方卡牌列表；实时显示羁绊激活（正面羁绊金色、负面羁绊朱红） |
| 战斗（放置自动） | 深墨底 + 场景背景；敌方在上、我方在下；底部加速、跳过按钮；挂机收益在主城领取 |
| 结算 | 胜利盖"捷"印，失败盖"败"印；战报用竖排公文格式写一段史实 |
| 将领详情 | 左侧主立绘 `full`，右侧竖排人物名 + 属性 + 技能 + 羁绊 + 史料小传 |
| 史册（图鉴） | 按阵营、派系分组的 `thumb` 网格；未获得的显示剪影 |
| 招募 | 抽卡展示用 `full` 立绘，传说卡出现时金印落下 |
| 剧情 | 石印风格插图 + 底部宣纸对话框 |

## 7. 动效原则

- 克制：淡入、盖章落下、卷轴展开；不用弹跳、果冻效果
- 盖章动效：缩放 1.3 → 1.0，80ms，伴随轻微震屏
- 传说卡：金框上缓慢流光，周期 3s
