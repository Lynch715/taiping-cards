# 03 资产管线（Codex 施工说明）

> 目标：把 GPT 生成的人物图和背景图，自动处理成尺寸完全统一的主立绘和各级缩略图。**全程只缩放、不裁切。**

## 1. 目录结构

```
assets/
  raw/
    characters/{id}.png        # GPT 原图：人物，透明底或纯色底
    backgrounds/{bg_id}.png    # GPT 原图：背景板 1024×1536
    fx/{fx_id}.png             # 传说卡特效层（透明 PNG，1024×1536）
  characters/{id}/
    full.png                   # 1024×1536 合成主立绘（无损母版，不进网页包）
    full.webp                  # 1024×1536，质量 85，网页详情页使用
    card.webp                  # 400×600
    mini.webp                  # 160×240
    thumb.webp                 # 96×144
  reports/
    pipeline_report.csv
    contact_sheet.png
data/characters.csv            # 人物表：id、背景、x_offset 等
docs/reference/                # 风格母图、文物和照片参考
tools/build_portraits.py
```

命名：`id` 一律小写拼音加下划线，阵营前缀 `tp_` / `qing_`（例：`tp_shi_dakai`）。

## 2. 脚本：`tools/build_portraits.py`

Python 3.11+，依赖 Pillow、numpy；去背景可选 `rembg`。

```
python tools/build_portraits.py            # 处理全部人物
python tools/build_portraits.py --id tp_shi_dakai
python tools/build_portraits.py --check    # 只出报告和对照表，不写文件
```

### 2.1 处理步骤（每个人物）

1. 读 `data/characters.csv`，取 `id`、`bg_id`、`x_offset`、`height_scale`
2. 读 `assets/raw/characters/{id}.png`
   - 有透明通道：直接用
   - 无透明通道：取四角像素均值作为底色，按色差容差（默认 ΔE < 12）抠成透明；`--rembg` 参数时改用 rembg
3. 求人物外框：alpha > 16 的像素包围盒
4. **缩放**（等比，Lanczos）：
   - `target_h = round(1300 × height_scale)`（height_scale 缺省 0.96；不在 0.90–1.00 范围内视为人物表错误，退出码 2）
   - `s = target_h / bbox高`
   - 若 `bbox宽 × s > 896`，改为 `s = 896 / bbox宽`
5. **定位**：缩放后人物外框底边对齐 y=1392，外框水平中心对齐 x = 512 + x_offset
6. **合成**：背景板 `assets/raw/backgrounds/{bg_id}.png`（必须是 1024×1536，不是则报错，不自动裁）
   - 人物脚下加一个椭圆阴影：中心 (人物中心x, 1392)，宽 = 人物宽 × 0.6，高 40px，黑色 35% 不透明度，高斯模糊 12px
   - 稀有度为 SSR 且存在 `assets/raw/fx/{id}.png` 时，叠加特效层（滤色混合 screen）
7. 输出 `full.png`，再把 `full.png` **整张**缩放出 `card` / `mini` / `thumb`（WebP，质量 85）

### 2.2 报告 `pipeline_report.csv`

每人一行：`id, src_w, src_h, bbox_x, bbox_y, bbox_w, bbox_h, height_scale, scale, final_h, warnings`

警告条件：

| 警告码 | 条件 | 含义 |
|---|---|---|
| `UPSCALE` | scale > 1.25 | 原图人物太小，放大后会糊，需要重出 |
| `EDGE_CUT` | 原图 bbox 贴边（距任一边 < 4px） | 人物很可能被原图边缘切掉，需要重出 |
| `WIDE` | 触发了按宽度缩放 | 人物姿势太张开，最终会显得比别人矮 |
| `NO_ALPHA_FALLBACK` | 用了色差抠图 | 需要人工看一下边缘有没有白边 |
| `BG_MISSING` | 背景板缺失 | 用中性灰宣纸底代替 |

### 2.3 对照表 `contact_sheet.png`

所有人物的 `card` 尺寸并排成网格，每张上画三条参考线：头顶线 y=6%（青色）、脚底基线 y=90.6%（红色）、左右安全边（灰色虚线）。下方写 id 和警告码。**这是我验收用的图**，每次跑完脚本请把它和报告一起提交。

## 3. 验收标准

- 全部人物脚底在同一基线，头顶不超过头顶线；final_h 与 1300 × height_scale 相差不超过 2px
- `pipeline_report.csv` 中没有 `UPSCALE`、`EDGE_CUT`
- 派生图与 `full.png` 比例完全一致（2:3），没有任何裁切
- 同一输入重复运行，输出逐字节一致（固定参数，不用随机）
